📚 BookSharing API Documentation

Security Notice: All endpoints use secure validation to prevent directory traversal attacks and unauthorized file access.
1. GET /api/resources.php - List Books
GET http://localhost/booksharing/api/resources.php

Query Parameters:

Parameter Type Required Description
page integer No Page number (default: 1)
limit integer No Items per page (default: 20, max: 50)
search string No Search in title and description
user_id integer No Filter by uploader user ID

Example Requests:

GET /api/resources.php - Get first 20 books

GET /api/resources.php?page=2&limit=10 - Get page 2 with 10 items per page

GET /api/resources.php?search=python - Search for "python"

GET /api/resources.php?user_id=5 - Get all books from user 5

Success Response (200):

{
  "success": true,
  "data": [
    {
      "id": 1,
      "title": "Python Guide",
      "description": "Complete Python tutorial...",
      "file_path": "1234567890_python.pdf",
      "user_id": 5,
      "created_at": "2025-04-20 10:30:00",
      "download_url": "download.php?id=1"
    }
  ],
  "pagination": {
    "current_page": 1,
    "total_pages": 5,
    "total_resources": 100,
    "per_page": 20,
    "has_next": true,
    "has_prev": false
  },
  "api_version": "1.0"
}
2. GET /api/download.php - Secure File Download
GET http://localhost/booksharing/api/download.php?id=RESOURCE_ID

Query Parameters:

Parameter Type Required Description
id integer Yes Resource ID from resources API

Example Request:

GET /api/download.php?id=1 - Download resource with ID 1

Success Response (200):

File is streamed to the client with proper headers:

  • Content-Type - Automatically detected MIME type
  • Content-Disposition - Triggers download dialog
  • Content-Length - File size in bytes

Error Responses:

400 Bad Request - Resource ID not provided or invalid

404 Not Found - Resource or file not found

403 Forbidden - Directory traversal attempt blocked or file access denied

🔒 Security Features

  • Directory Traversal Protection: Prevents access to files outside uploads directory
  • SQL Injection Prevention: Uses prepared queries and escaped strings
  • MIME Type Validation: Proper content-type headers for all file types
  • File Validation: Verifies file exists and is readable before serving
  • Access Control: Can be extended with user authentication checks

📝 Usage Examples

JavaScript/Fetch

// Fetch list of books
fetch('/booksharing/api/resources.php?search=python&limit=10')
  .then(response => response.json())
  .then(data => {
    console.log('Books:', data.data);
    console.log('Pages:', data.pagination);
  });

// Download a book
window.location.href = '/booksharing/api/download.php?id=1';

cURL/Command Line

# Get resources
curl http://localhost/booksharing/api/resources.php?search=python

# Download file
curl -O http://localhost/booksharing/api/download.php?id=1
